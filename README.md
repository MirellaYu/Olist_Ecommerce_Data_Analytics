# 📊 Olist E-Commerce Analytics

## Descripción del proyecto

Este proyecto desarrolla un análisis del desempeño comercial y operativo de un e-commerce utilizando el Brazilian E-Commerce Public Dataset by Olist compuesto por 8 tablas: olist_customers_dataset, olist_geolocation_dataset, olist_order_items_dataset, olist_order_payments_dataset, olist_order_reviews_dataset, olist_orders_dataset, olist_products_dataset, olist_sellers_dataset. El objetivo es transformar datos transaccionales en información útil para el análisis de ventas, clientes, productos, vendedores, geografía, logística y satisfacción del cliente.
El proyecto sigue un flujo de análisis de datos de extremo a extremo:

**Excel / Power Query → SQL Server → Power BI**

A través de este proceso se realizó la limpieza y transformación de los datos, la construcción del modelo relacional, el análisis mediante consultas SQL y la creación de un dashboard interactivo para explorar los principales indicadores del negocio.

---

## Objetivos del análisis

- Analizar la evolución de las ventas y los pedidos.
- Identificar las principales categorías y productos.
- Analizar el comportamiento y recurrencia de los clientes.
- Analizar el desempeño y distribución de los vendedores.
- Examinar la distribución geográfica de clientes y vendedores.
- Evaluar tiempos de entrega y cancelaciones.
- Analizar la satisfacción del cliente mediante las reseñas.
- Construir indicadores que faciliten la interpretación del desempeño
  del negocio.

---
## 🎯 Análisis clave

### Rendimiento comercial
- Evolución de ingresos y pedidos a lo largo del tiempo.
- Ticket promedio por pedido.
- Categorías y subcategorías con mayor volumen e ingresos.
- Participación de las categorías en los ingresos.
- Evolución mensual de las ventas.

### 👥 Clientes
- Clientes únicos y nuevos clientes.
- Frecuencia de compra y clientes recurrentes.
- Segmentación de clientes según comportamiento de compra.
- Ingresos por cliente.
- Distribución geográfica de los clientes.

### 🏪 Vendedores
- Ingresos y pedidos por vendedor.
- Principales vendedores por volumen de ventas.
- Distribución de vendedores según volumen de pedidos.
- Relación entre pedidos y cantidad de vendedores por estado.

### 🚚 Operaciones y logística
- Tiempo promedio de entrega.
- Pedidos entregados dentro y fuera del plazo estimado.
- Evolución de cancelaciones.
- Estados con mayores tiempos promedio de entrega.
- Comportamiento de las valoraciones de los pedidos.

---

## Herramientas utilizadas

- **Excel / Power Query:** limpieza y transformación de datos.
- **Power Pivot:** modelado, relaciones y medidas.
- **Motor de base de datos:** SQL SERVER (desarrollo local).
- **Power BI:** KPIs, visualizaciones y dashboard interactivo.
- **Dataset:** Brazilian E-Commerce Public Dataset by Olist (Kaggle)
- **Lenguaje:** SQL estándar
