# Análisis y Modelado en Excel

Este archivo documenta el proceso de preparación y análisis de datos
del proyecto Olist E-Commerce Analytics.

### Procesos realizados

- Limpieza y transformación de datos mediante Power Query.
- Preparación de tablas para el análisis.
- Construcción del modelo de datos mediante Power Pivot.
- Creación de medidas y KPIs.
- Análisis mediante tablas dinámicas y segmentadores.
- Validación de resultados para su posterior visualización en Power BI.
