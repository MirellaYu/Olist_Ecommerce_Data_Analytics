# 📊 Preparación y Análisis de Datos | Excel

## Descripción

En esta etapa se realizó la **limpieza, transformación y preparación de los datos** del Brazilian E-Commerce Public Dataset by Olist utilizando **Excel y Power Query**.

Posteriormente, se construyó el modelo de datos mediante **Power Pivot**, estableciendo relaciones entre las principales tablas y desarrollando medidas para el análisis de los indicadores del negocio.

## 🔧 Proceso realizado

- Limpieza y transformación de los datasets mediante Power Query.
- Estandarización de tipos de datos y campos.
- Tratamiento de valores nulos y registros inconsistentes.
- Preparación de las tablas para su análisis.
- Construcción del modelo relacional en Power Pivot.
- Creación de relaciones entre las tablas.
- Desarrollo de medidas y KPIs.
- Análisis mediante tablas dinámicas y segmentadores.

## 📈 Análisis desarrollado

El archivo incluye análisis relacionados con:

- Ventas e ingresos.
- Pedidos y evolución temporal.
- Categorías de productos.
- Clientes y comportamiento de compra.
- Vendedores.
- Métodos de pago.
- Distribución geográfica.
- Valoraciones y pedidos.
- Indicadores comerciales y operativos.
